# NOTE ON WHAT IS DELIBERATELY ABSENT
#
# lightfm, implicit and scikit-surprise were listed here early on as intended
# collaborative-filtering backends, but the implementation uses item-item cosine
# similarity from scikit-learn instead (see app/ml/collaborative.py for why), so
# none of them is imported anywhere in the codebase.
#
# They are removed rather than left unused because they are not free:
#   * lightfm 1.17 (last released 2020) fails to build against modern
#     setuptools -- its setup.py assumes __builtins__ is a module, and pip's
#     isolated build environment gives it a dict, so the image build dies with
#     "AttributeError: 'dict' object has no attribute '__LIGHTFM_SETUP__'"
#   * all three compile from source, adding minutes to every build
#
# If matrix factorisation is adopted later, LightFM slots in behind the existing
# ItemCF interface -- add it back then, on a version that still builds.
